---

## 🌟 Capabilities

- **Turn-by-Turn GPS Telemetry**: Real-time breadcrumb streaming via Supabase PostgreSQL and WebSockets.
- **Stage Progression Workflow**: `START_PICKUP` ➔ `ARRIVED_AT_STORE` ➔ `PICKED_UP` ➔ `ARRIVED_AT_CUSTOMER` ➔ `DELIVERED`.
- **Payment Collection**: Digital UPI intent QR generation and Cash on Delivery (COD) collection audit log.
